Welcome to Martindale.

The following PHP exercise will test your knowledge of making RESTful API calls along with connecting to a database to fetch and stored in a relational database.

For the purpose of this exercise, you are provided with a sample registration form. Your task is the POST the data from this registration form to submit page. The submit page will make use of a predefined APIStorage API function to store the data of the form into a relation in a database.

Upon successful data entry, the API will return an insert ID to identify the last inserted record. You are then required to redirect from the submit page to the data retrieval page. On this page, you will open a connection to the MySQL database with the credentials provided and use the insert ID provided during insert to pull the record information and display in a simple tabular format.

Steps to complete this exercise:

  1. Verify the Input fields in the "index.php" form.
  2. Modify the "submit.php" page to receive the data from "index.php". The form method should be POST.
  3. Perform the necessary server side validation, such as the no numbers in the names, correct e-mail address format, date of birth NOT in the future, ZIP code 5 digits, etc.
  4. POST the data to the API endpoint (provided in submit.php). This should be a simple POST. You may use the PHP cURL library.
  5. Receive and decode the response from the API. The response returned from the API is json encoded.
  6. Redirect to "success.php" page.
  7. Create a connection to the database and fetch the information for the newly inserted record.
  8. Display the data in a simple HTML table.
